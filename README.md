# TQM Study Desk

Extract the ZIP and open index.html in a browser. Keep index.html, style.css, topics.js and app.js together. The site works offline without installing packages or starting a server.

Select a unit in the top bar and a topic in the sidebar. On a small screen, expand “Topics in Unit” under the top bar. The “Study first” label identifies the recommended CDAP half. Start a revision session with Unit 3 Part 1, Unit 4 Part 1, Unit 1 Part 2, Unit 2 Part 2 and Unit 5 Part 2, then cover the remaining halves.

Each page starts with a diagram or comparison matrix. Read the topic answer, cover it, redraw the diagram and explain each bold subheading from memory. Print from your browser to print only the current topic.

## Project files

- index.html — accessible page structure and navigation landmarks
- style.css — desktop, mobile and print presentation
- topics.js — editable answer text, revision diagrams' labels, CDAP groups and lecture slide references
- app.js — navigation, diagrams and keyword highlighting

Content follows the five GEA1404 lecture decks and the CDAP part assignments. Worked illustrations supplement the lecture examples.
